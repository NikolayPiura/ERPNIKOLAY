# PIURA ERP

Единая оболочка для всех согласованных сервисов PIURA. Старые экраны, данные и интерактивная логика сохранены; визуальный слой приведён к двум общим монохромным режимам: **Тёмная · Premium** и **Светлая · Лёгкая**.

Удалён только отдельный Personal Finance / Finance OS. Остались: обзор, эффективность, утро, учёт времени, ПС №1, админ-шкала, мои динамики, доходы, структура фондов, PFF, Москва и SAFE.

```bash
npm run dev
npm test
npm run check
```
