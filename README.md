# PIURA ERP

Единая оболочка для всех согласованных сервисов PIURA. Старые экраны, данные и интерактивная логика сохранены; визуальный слой приведён к двум общим режимам: **Тёмная · Premium** и **Светлая · Air**. Цвет используется сдержанно — для статусов, графиков, прогресса и важных показателей.

Удалён только отдельный Personal Finance / Finance OS. Остались: обзор, эффективность, утро, учёт времени, ПС №1, админ-шкала, мои динамики, доходы, структура фондов, PFF, Москва и SAFE.

Сайт публикуется бесплатно через GitHub Pages прямо из ветки `main`. Платные базы, хостинги и GitHub Actions не требуются.

## Govee Life

ERP не хранит API-ключ лампы в открытом коде. Управление питанием, яркостью и цветом проходит через `integrations/google-apps-script/PiuraBridge.gs`; ключ задаётся один раз в Script Properties как `GOVEE_API_KEY`.

```bash
npm run dev
npm test
npm run check
```
