# PIURA ERP ↔ Google Drive и Google Docs

Этот мост нужен потому, что статическая страница GitHub Pages не может сама безопасно редактировать Google Docs.

1. Откройте [script.google.com](https://script.google.com/) и создайте проект.
2. Вставьте содержимое `AdminScaleSync.gs` в файл `Code.gs`.
3. Нажмите **Deploy → New deployment → Web app**.
4. Выберите **Execute as: Me** и доступ для пользователя, который открывает ERP.
5. Скопируйте адрес `/exec` в главные настройки ERP: **⚙ → Сохранность всех данных ERP → Адрес Google Apps Script**. Админ-шкала автоматически использует тот же адрес.

По желанию добавьте в **Project settings → Script properties** свойство `SYNC_TOKEN`. Такой же ключ укажите в настройках Admin Scale. В ERP ключ сохраняется только в `localStorage` текущего браузера.

Мост выполняет две задачи:

- сохраняет полную резервную копию данных всех модулей в `PIURA_ERP_BACKUP.json` на Google Drive и раз в день создаёт архивный снимок;
- синхронизирует админ-шкалу с документами «Цели», «Планы» и «Программы» в обе стороны.

ERP сразу показывает локальный снимок и обновляет его в фоне. Галочка делает строку зелёной в Google Docs, редактирование меняет текст, удаление удаляет строку. Изменения и зелёные строки в Docs подхватываются при открытии сервиса, при возвращении на вкладку, раз в минуту или по кнопке синхронизации.

После изменения `AdminScaleSync.gs` откройте **Deploy → Manage deployments → Edit → New version → Deploy**. Старый адрес `/exec` при этом не меняется.
