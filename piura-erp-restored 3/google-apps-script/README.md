# PIURA ERP ↔ Google Drive и Google Docs

Этот мост нужен потому, что статическая страница GitHub Pages не может сама безопасно редактировать Google Docs.

Мост уже связан с ERP постоянным адресом `/exec`; пользователь не вводит URL,
ключи или токены в настройках. При обновлении серверной части:

1. Откройте существующий проект в [script.google.com](https://script.google.com/).
2. Замените `Code.gs` содержимым `AdminScaleSync.gs`.
3. Нажмите **Deploy → Manage deployments → Edit → New version → Deploy**.
4. Сохраните **Execute as: Me** и доступ веб-приложения для пользователя ERP.

Каждый рабочий запрос получает краткоживущий Firebase ID token автоматически.
Скрипт проверяет его через Google Identity Toolkit и разрешает операции только
владельцу `kol9932@gmail.com`. Свойство `SYNC_TOKEN` допускается лишь как
аварийный серверный ключ и не должно храниться в браузере или исходном коде ERP.

Мост выполняет две задачи:

- сохраняет полную резервную копию данных всех модулей в `PIURA_ERP_BACKUP.json` на Google Drive и раз в день создаёт архивный снимок;
- синхронизирует админ-шкалу с документами «Цели», «Планы» и «Программы» в обе стороны.

ERP сразу показывает локальный снимок и обновляет его в фоне. Галочка делает строку зелёной в Google Docs, редактирование меняет текст, удаление удаляет строку. Изменения и зелёные строки в Docs подхватываются при открытии сервиса, при возвращении на вкладку, раз в минуту или по кнопке синхронизации.

Старый адрес `/exec` при выпуске новой версии не меняется, поэтому повторная
настройка ERP и повторная авторизация пользователя не требуются.
